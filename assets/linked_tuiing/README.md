# 튀잉 연결형 키링 원본

사용자가 제작을 요청한 Google 문서의 기본·황올·탄·안튀잉 원본입니다.
`*_original.png`는 문서에서 받은 PNG 그대로 보존했습니다.
각 SVG는 원본의 정확한 4배 픽셀 반복을 확인한 뒤 동일 색상·투명도의 픽셀을 사각 경로로 옮긴 소스입니다.
생성형 이미지 보정·색 변경·픽셀 추가는 하지 않았습니다.

소스 SVG의 단위는 원본 픽셀 격자 기준입니다. 현재 출력은 원래 그림 폭 30mm를 유지하며, `configs/a3_release.json`과 `configs/a3_placements.json`에서 A3 배치를 관리합니다.
`provenance.json`에 원본 해시와 문서 이미지 번호를 기록합니다.
