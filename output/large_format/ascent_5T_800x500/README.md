# 어센트 5T · 800 × 500mm

**5T 아크릴, 가로 800 × 세로 500mm, 100%, 자동 맞춤 해제.** 원본 그림판 25개와 투명 받침 5개, 총 30조각입니다.

- `01_PRINT.pdf` 또는 `01_PRINT_300ppi.png`: 인쇄 원본. 파란 위치 기준선은 자르지 않습니다.
- `03_CUT_ONLY.pdf` 또는 SVG: 레이저 재단 전용. 내부 홈부터 재단합니다.
- `04_WHITE_INK_MASK.pdf` / PNG: 백색 분판.
- `02_MASTER.pdf` / AI: 레이어 편집본. VectorCraft 파일의 편집용 그림은 300ppi이며 최종 인쇄는 `01_PRINT`를 사용합니다.
- `preview.png` 등은 검토용입니다.

받침 104×38mm, 홈 도면 19.80×4.85mm 8개, 같은 열의 홈 사이 3.65mm. 한 패널을 받치는 좌우 홈의 중심선 높이를 맞췄습니다. 그림판 돌기는 폭 20mm, 어깨에서 끝까지 깊이 5.10mm입니다. 재단 폭 0.20mm를 가정한 두께 방향 여유는 0.05mm입니다. 5개 받침은 동시에 20개 판을 수용하며 나머지 5판은 교체 가능성을 확인해야 합니다. 실제 두께·커프·끼움·강도는 미검증입니다.
