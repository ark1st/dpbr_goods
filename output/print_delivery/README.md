5페이지 구성은 카데나 1, 키네시스 2, 라라 1, 카인 1, 렌 2, 제로 3, 엔젤릭버스터 1세트입니다. 각 세트에 5T 받침이 하나씩 들어갑니다. 그림판 돌기는 폭 20.00mm, 어깨에서 끝까지 5.10mm입니다. 받침 홈의 칼선 치수는 19.80×4.85mm입니다. 판 두께 5.00mm와 절단폭 0.20mm를 기준으로 두께 방향 총 여유를 0.05mm로 잡았습니다. 이 파일은 커프 보정이 포함되어 있으므로 인쇄소에서는 칼선 중심을 따라 100%로 재단하세요.

마지막 A3 키링판은 로고 59개, 가람이 11개, 단팽이 11개, 작은 튀잉 줄줄이 키링 4세트(4종 각 4개)로 총 97개입니다. 튀잉은 제공받은 28.67×43.38mm 원본을 사용했으며 각 조각에 지름 2.50mm의 위·아래 연결 구멍과 백색 분판이 들어 있습니다. 가람이와 단팽이의 백색 밑인쇄는 RIP에서 그림 알파 기준으로 설정하세요. [전체 배치](danba_keyrings/preview.png) · [로고 칼선 변경 전후](danba_keyrings/cut_detail.png)

PNG는 300ppi이며 각 AI는 같은 대지와 원점을 사용합니다. 100% 배율로 가져오고 파란 외곽선을 맞추세요. 빨간 `LASER_CUT` 레이어만 재단합니다. 파란 `CORNER_REFERENCE`는 위치 맞춤용입니다. AI는 Illustrator에서 열 수 있는 PDF 호환 벡터 파일입니다. 투명 그림의 백색 밑인쇄는 인쇄소 RIP에서 설정하세요.
