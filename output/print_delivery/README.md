# 아크릴 인쇄소 전달 파일

1·2페이지는 기존 인쇄분을 사용합니다. 아래 각 행에서 PNG와 AI를 한 쌍으로 받으세요.

| 판 | 대지 · 재료 | 인쇄 PNG | 칼선과 위치 기준선 AI |
|---|---|---|---|
| 3 · 캐릭터 스탠드와 키링 | A3 가로 420×297 mm · 3T | [PNG](page03/01_PRINT_300ppi.png) | [AI](page03/02_CUT_WITH_BLUE.ai) |
| 4 · 렌, 무한이(G 후드) 일반 키링 14개, 작은 풍뎅이와 혼합 키링 | A3 가로 420×297 mm · 3T | [PNG](alternative_page04/01_PRINT_300ppi.png) | [AI](alternative_page04/02_CUT_WITH_BLUE.ai) |
| 5 · 어센트 30조각 | 800×500 mm · 5T | [PNG](alternative_800x500/01_PRINT_300ppi.png) | [AI](alternative_800x500/02_CUT_WITH_BLUE.ai) |

PNG는 300ppi이며 각 AI는 같은 대지와 원점을 사용합니다. 100% 배율로 가져오고 파란 외곽선을 맞추세요. 빨간 `LASER_CUT` 레이어만 재단합니다. 파란 `CORNER_REFERENCE`는 위치 맞춤용입니다. AI는 Illustrator에서 열 수 있는 PDF 호환 벡터 파일입니다. 투명 그림의 백색 밑인쇄는 인쇄소 RIP에서 설정하세요.
