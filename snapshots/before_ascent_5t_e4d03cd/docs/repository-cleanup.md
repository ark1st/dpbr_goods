# 저장소 전수 정리 · 2026-11-22

## 브랜치와 보관

- `main`: 편집 마스터, 현재 그림 소스, A3 생성·검사 코드.
- `output_len`: 현재 A3 제작 파일, 두께별 대안, 시안·ZIP·검사 결과.
- `raw`: 정리 전 main·output_len·output_len_sleeg·output의 전체 스냅샷과 로컬에만 있던 자료.

[백업 manifest](https://github.com/ark1st/dpbr_goods/blob/raw/BACKUP_MANIFEST.json)에 파일별 SHA-256, Git 블롭, 원래 브랜치 HEAD를 기록했습니다.
Windows 줄바꿈 때문에 Git 저장 바이트와 다른 파일은 `local_worktree/`에 별도로 보존했습니다.
100MiB를 넘는 로컬 ZIP은 40MiB씩 분할해 보존하고 결합 해시를 검증했습니다. Git 이력을 재작성하지 않았습니다.

정리 중 새 원격 커밋 bcc9d2e가 들어와 `snapshots/output_len_incoming/`에 추가 보관했습니다.
Len PAD 그림은 main으로 가져왔고 본품 7조각을 A3 선택안으로 옮겼습니다. 과거 320×370mm 대지와 시험편은 현재 출력에서 제외했습니다.

## 정리와 재발 방지

구형 생성기·설정·티셔츠 작업본·중복 원본은 main에서 퇴역했습니다. 가람·단팽이·단풍바람 로고 마스터는 main에 그대로 있습니다.
로컬 구버전 출력 906개와 퇴역 소스 36개, 중복 원본 등을 정리했습니다. 이전 단바·티셔츠 등은 raw에서 찾을 수 있습니다.
현재 목록은 A3 manifest만 사용합니다. 예전 시험편 안내와 잘못된 수량·장수 안내를 제거했습니다.

과거 입력은 `tmp/source_cache`에 복원합니다. 재생성할 때 output에 구버전 폴더를 되살리지 않습니다.
미등록 출력, 빠진 필수 파일, ZIP 멤버의 누락·중복, 시험편이 나타나면 배포 검사를 실패시킵니다.
보관본 전체의 바이트와 분할 원본도 매 전체 검사에서 확인합니다. 과거 파일을 현재 제작 합격 수에 합산하지 않습니다.

현재 확정 출력은 3T 최소2장·56조각입니다. 이후 요청으로 단팽이·로고 키링3개를 제외하고 카데나를 두 시트에 분산했습니다. 도트 렌은50mm·발 아래 돌기로 수정했습니다. 이전3장 파일은 raw의 `snapshots/before_two_sheet/`에 보존했습니다. 새 PAD는 별도 선택안1장·7조각이며5T는 대안입니다.
`REPOSITORY_AUDIT.json`은 원본 보존, `LASER_PATH_AUDIT.json`은 현재 칼선,
`RELEASE_VALIDATION.json`은 전체 형식·렌더·ZIP 검사 범위를 기록합니다.

## 한계

임시 렌더·다운로드 캐시·설치 라이브러리는 Git 제작물이 아니며 tmp에 둡니다. 관련 없는 개인 폴더는 정리하지 않았습니다.
raw에는 과거 불량 칼선·폐기 시안도 기록 목적으로 있습니다. raw의 해시 검증은 제작 승인이 아닙니다.
외부 30조각은 수정하지 않고 발견 사항을 별도 보고합니다. 실물 절단·끼움·인쇄 정합은 아직 검증하지 않았습니다.
GitHub CI에서는 AI·PDF 및 원본 대조·패키지 검사를 실행합니다. VectorCraft가 필요한 SVG·네이티브 검사는 게시 전 로컬 전체 검사에서 수행합니다.
