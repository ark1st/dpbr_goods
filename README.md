# 단풍바람 굿즈 제작

[인쇄소용 PNG·칼선 AI와 페이지별 링크](output/print_delivery/README.md)

1·2페이지는 기존 인쇄분을 사용합니다. 3페이지는 첨부된 아크릴판의 그림·칼선·파란 기준선을 보존하고 자투리에 캐릭터 스탠드와 키링을 추가한 공통판입니다. 4페이지는 렌 스탠드와 추가 키링·스탠드를 담은 A3이고, 5페이지는 어센트 11세트(그림판 39개·받침 11개)를 담은 800×500mm 5T입니다.

단풍바람 로고·가람이·단팽이 키링은 [A3 3T 양산판](output/print_delivery/danba_keyrings)으로 따로 출력할 수 있습니다.

[재사용 스킬](skills/reference-acrylic-cuts/SKILL.md) · [제작 규칙](docs/a3-release.md) · [칼선 품질 기준](docs/laser-cut-quality.md) · [전체 검사](output/RELEASE_VALIDATION.json)

ZIP은 생성하지 않습니다. 원본에 백색판이 없는 그림은 인쇄소 RIP에서 그림 알파 기준 백색 생성이 필요합니다. 실물 가공·끼움·강도는 미검증입니다.
