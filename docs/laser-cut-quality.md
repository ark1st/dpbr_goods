# 레이저 칼선 생성·배포 기준

2026-11-20 실물 절단에서 느린 미세 이동과 거친 절단면이 보고되었습니다.
기존 단바 합본은 44,278개 직선 선분을 사용했습니다. 폐곡선·치수 검사만으로는
경로의 가공 품질을 확인할 수 없었으므로 다음 검사를 필수로 추가했습니다.

## 생성

- 인쇄 그림과 위치는 유지합니다. `poly_path()`는 시안·마스크용입니다.
- 실제 칼선은 `laser_paths.cut_path()` 또는 `draw_cut_pdf()`로 생성합니다.
- 극미세 오프셋 흔적을 제거하고 연속 접선을 가진 3차 베지어 곡선으로 맞춥니다.
- 원형 구멍의 중심과 지름, 돌기·홈·직선과 모따기의 모서리를 보존합니다.
- 원래 외곽과 곡선 외곽의 양방향 거리 상한은 0.035mm입니다.
  곡선 평가용 분할 오차는 0.001mm입니다. 이것은 제조 공차 보증이 아닙니다.
- 자기교차·열린 경로·길이 0·과다 선분·연속 미세 직선이 발견되면 생성을 실패시킵니다.
- 외부 캐릭터 30개 원본은 사용자의 보존 요청에 따라 수정하지 않습니다.
  발견 사항은 검사 보고서에서 별도로 표시하며 일반 합격에 섞지 않습니다.
  기하학적 이동이 없는 길이 0 명령과 0.0001mm 이하 변환 반올림만 수치 기록으로
  허용합니다. 그보다 큰 자기교차·중복·밀집 경로는 외부 원본이어도 배포를 차단합니다.

## 매 배포의 필수 검사

1. `python -m unittest discover -s tests` — 실제 문제 경로와 치수 보존 회귀 검사.
2. 현재 제작판 생성기를 순서대로 실행합니다.
3. `python scripts/verify_laser_paths.py` — 현재 모든 칼선 SVG·AI·PDF·VectorCraft 검사.
4. `python scripts/verify_release.py` — 치수·레이어·인쇄·조립·ZIP 검사와 PDF 렌더.
5. 확대 칼선 및 전체 판 렌더를 직접 확인합니다. 잘못된 접선·홈·구멍이 없어야 합니다.
6. `output/LASER_PATH_AUDIT.json`의 errors가 비어 있어야 배포할 수 있습니다.
7. 검사한 파일과 배포 파일의 SHA-256을 대조합니다. ZIP 내부도 현재 파일과 일치해야 합니다.
   SVG·문서·JSON의 줄바꿈은 저장소 규칙에 맞춰 LF로 정규화하여 비교하고,
   AI·PDF·PNG·VectorCraft 같은 바이너리는 원시 바이트로 비교합니다.

소스는 main, 결과물은 output_len에 올립니다. 구버전은 보관용으로 분류하며 새 제작에 사용하지 않습니다.
자동 검사는 실제 장비의 가감속·출력·초점·재료·끼움 상태를 검증하지 못합니다.
수정 후 첫 제작은 같은 재료에서 한 조각을 비교 절단하여 시간과 절단면을 확인합니다.

## A3 제작판

현재 추가 이미지·줄줄이 키링·어센트·Len 제작판은 `output/a3_release`입니다.
재생성과 병합 근거는 [A3 배포 규칙](a3-release.md)을 따릅니다.
배율 1, 그림·백색·칼선의 동일한 강체 변환, 보호 원본 30개 전부 보존을 검증합니다.
`verify_release.py`는 A3 7대지와 6개 패키지를 추가 검사합니다.
