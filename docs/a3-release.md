# 현재 A3 생성·검사

선택 재료는 3T, 대지는 가로420×297mm, 배율은100%입니다. 조각 간격3mm 이상과 대지 가장자리8mm 이상을 유지합니다.

| 그룹 | 조각 | 현재 선택 | 두께 대안 |
|---|---:|---|---|
| 02_extra_sheet | 3T41 / 5T39 | 혼합1: 카데나 판2개 포함 | 5T에는 카데나 없음 |
| 05_len | 3T15 / 5T12 | 혼합2: 카데나 나머지3개 포함 | 5T에는 카데나 없음 |
| 06_len_pad | 7 | 별도 선택3T 1장 | 5T 1장 |

확정분은최소2장·56조각입니다. 단팽이1개·로고2개를 제외했습니다. PAD를 추가하면3장·63조각입니다. 두께별 대안까지 포함한6대지·6ZIP 전부를 검사합니다.
모든 시험편·시험키·샘플 받침을 제외합니다. Len 일반7조각에 DOT 캐릭터1개와 튀잉4개를 더한12조각입니다.
새튀4개는 추가 이미지에 배치해 줄줄이 키링8개를 한 번씩만 출력합니다.

## 원본 복원과 재생성

`configs/a3_release.json`의 커밋·SHA-256으로 입력을 고정합니다. `scripts/source_cache.py`는 `tmp/source_cache/<commit>/`에만 복원합니다.
어센트 전체 AI는 raw의 분할3파일을 합쳐 해시를 확인한 뒤 카데나5조각만 선택합니다.
Len PAD는 raw 보관본 스냅샷(len_pad_bud_guard, 23fa338)의7조각을 회전·이동합니다. 캐릭터 허리에 보강 리브가 들어간 마스터이며 원래 치수와15폐곡선을 유지하고 과거 시험편은 읽지 않습니다.

```sh
python scripts/build_a3_release.py
python scripts/package_a3_release.py
python -m unittest discover -s tests
python scripts/verify_release.py
```

공유 중간 파일을 쓰므로 생성 명령은 순서대로 실행합니다.
`configs/a3_placements.json`의 검토한 이동·회전 값을 재사용합니다. 조각ID·원본 외곽 크기·간격·대지 경계를 확인하고 치수가 달라지면 자동 축소하지 않고 실패합니다.
Python으로 실루엣을15도 단위로 회전·이동하고 실제 벡터 거리로 간격을 확인했습니다. 카데나 판2개를 추가 이미지 오른쪽 빈 공간에, 나머지를Len 시트에 옮겼습니다.
구멍을 뺀56조각의 실제 재료 면적은A3 한 장보다 큽니다. 2장 배치가 성립하므로 장수는 최소입니다. 정확한 면적·하한·성립 장수는 `A3_VALIDATION.json/minimum_sheet_proof`로 다시 계산합니다. 절단 시간이나 가장 작은 점유 사각형까지 최적이라는 뜻은 아닙니다.
도트 렌 그림은 사용자 요청으로76→50mm로 바꿨습니다. 돌기 중심을 원본x90px(발 중심)에 놓고18mm 폭·3T2.6mm 삽입깊이를 보존했습니다. 공통 받침과홈, 일반 렌 크기는 유지합니다. 새 곡선은 `scripts/len_dot_part.py`에서 `laser_paths.cut_path`로 생성합니다.

## Len 홈 끼움 보정 (이슈 #1)

원본 Len 홈은 판 표기 두께와 같은18.8×3.0(5T는18.8×5.0)mm이고 칼 폭 보정이 없어 실물이 헐렁했습니다.
`configs/a3_release.json`의 `len_slot_fit`로 Len 일반·패드 받침의 홈8개씩만 다시 그립니다(`laser_paths.slot_path`).
홈 중심·방향·모서리반경0.35mm, 외곽·돌기·그림·보호 원본(카데나3.2×20.2 등)은 바꾸지 않습니다.

| 두께 | 칼 폭 | 판 두께 | 두께 여유 | 좌우 여유 | 그리는 홈 |
|---|---:|---:|---:|---:|---|
| 3T | 0.15 | 3.0 | 0.05 | 0.2 | 17.9×2.90mm |
| 5T | 0.20 | 5.0 | 0.05 | 0.2 | 17.8×4.85mm |

홈 너비 = 판 두께 + 두께 여유 − 칼 폭. 홈 길이 = 돌기18 + 좌우 여유 − 2×칼 폭(돌기도 칼 폭만큼 줄어듦).
값은 표준 시작값이며 실측이 아닙니다. 장비 칼 폭이나 판 실측 두께가 다르면 이 설정만 바꿔 다시 생성합니다.
`verify_a3_release.py`는 Len 시트마다 보정 홈8개·원래 치수 홈0개를 확인합니다.

## 검사 범위

그림·백색·칼선에 같은 강체 변환을 적용합니다. 칼선은 원래 베지어 제어점을 직접 변환해 PDF Form 행렬 반올림 오차를 피합니다.
보호 원본30조각은 다시 피팅하지 않습니다. 위치가 바뀐 실제 칼선을 대조해 보호 원본으로 분류하며, 주변 사각 영역만 보고 다른 조각까지 보호 처리하지 않습니다.

내보내기 오차 상한은0.002mm입니다. 소유한 외곽을 곡선으로 정리할 때 양방향 거리 상한은0.035mm입니다.
미세 지그재그·중복·교차·열린 경로를 검사하고, PDF·AI·SVG·VectorCraft의5형식×6대지를 모두 확인합니다.
PNG 해상도, 원본 인쇄PDF와 마스터의 픽셀 일치, ZIP 필수 구성·누락·중복·해시도 검사합니다.
실제 검사 수와 보호 원본 발견 사항은 `LASER_PATH_AUDIT.json`, 전체 범위는 `RELEASE_VALIDATION.json`에 기록합니다.

## 제작 시 주의할 파일 구분

AI는 PDF 호환 레이어이며 네이티브 편집본은 VectorCraft입니다. 편집 그림은600ppi이고 원본 데이터를 유지한 인쇄PDF는 별도입니다.
파란 기준 사각형은 재단선이 아닙니다. 백색판이 없는 그림은 RIP에서 백색을 설정합니다.
실물은 미검증입니다. 카데나의 좌우 홈 약0.195mm 높이 차이와 원래3mm 돌기도 보존했습니다.
raw의 보관 해시 검사는 과거 불량 도안의 제작 승인이 아닙니다.
