# 현재 A3 생성·검사

선택 재료는 3T, 대지는 가로420×297mm, 배율은100%입니다. 조각 간격3mm 이상과 대지 가장자리8mm 이상을 유지합니다.

| 그룹 | 조각 | 현재 선택 | 두께 대안 |
|---|---:|---|---|
| 02_extra_sheet | 3T43 / 5T39 | 혼합1: 양검 캐릭터·키링·카데나 판2개 포함 | 5T에는 카데나 없음 |
| 05_len | 3T16 / 5T12 | 혼합2: 양검 받침·카데나 나머지3개 포함 | 5T에는 카데나 없음 |
| 06_len_pad | 7 | 출력 보류 · 원본 배치 참고용 | 5T도 보류 |
| 11_ascent_remaining | 25 | 카데나 제외·독립3T 2장 | 없음 |
| 09_yanggum | 3T3 | 단독 배치 참고용 · 혼합2장에 이미 포함 | 5T 미제작 |

양검3조각을 포함한 혼합2장59조각과 별도어센트2장25조각으로 확정4장84조각입니다. 단팽이1개·로고2개는 제외했습니다. Len PAD는 보류합니다. 두께별 대안·보류 원본 배치를 포함한9대지·8ZIP 전부를 검사합니다.
양검 스탠드·키링은 혼합판에 포함하며 단독09_yanggum은 추가 출력하지 않는 참고용입니다. 양검은 3T만 만들었고 5T 대안은 아직 없습니다. 대지의 칼선·인쇄·ZIP도 같은 검사로 확인합니다.
모든 시험편·시험키·샘플 받침을 제외합니다. Len 일반7조각에 DOT 캐릭터1개와 튀잉4개를 더한12조각입니다.
새튀4개는 추가 이미지에 배치해 줄줄이 키링8개를 한 번씩만 출력합니다.

## 원본 복원과 재생성

`configs/a3_release.json`의 커밋·SHA-256으로 입력을 고정합니다. `scripts/source_cache.py`는 `tmp/source_cache/<commit>/`에만 복원합니다.
어센트 전체 AI는 raw의 분할3파일을 합쳐 해시를 확인한 뒤 카데나5조각만 선택합니다.
Len PAD는 raw 보관본 스냅샷(len_pad_bud_guard, 23fa338)의7조각을 회전·이동합니다. 캐릭터 허리에 보강 리브가 들어간 마스터이며 원래 치수와15폐곡선을 유지하고 과거 시험편은 읽지 않습니다.

```sh
python scripts/build_a3_release.py
python scripts/package_a3_release.py
python -m unittest discover -s tests
python scripts/verify_release.py
```

공유 중간 파일을 쓰므로 생성 명령은 순서대로 실행합니다.
`configs/a3_placements.json`의 검토한 이동·회전 값을 재사용합니다. 조각ID·원본 외곽 크기·간격·대지 경계를 확인하고 치수가 달라지면 자동 축소하지 않고 실패합니다.
Python으로 실루엣을15도 단위로 회전·이동하고 실제 벡터 거리로 간격을 확인했습니다. 카데나 판2개를 추가 이미지 오른쪽 빈 공간에, 나머지를Len 시트에 옮겼습니다.
양검을 포함한 혼합59조각의 구멍을 뺀 실제 재료 면적은A3 한 장보다 큽니다. 2장 배치가 성립하므로 장수는 최소입니다. 정확한 면적·하한·성립 장수는 `A3_VALIDATION.json/minimum_sheet_proof`로 다시 계산합니다. 절단 시간이나 가장 작은 점유 사각형까지 최적이라는 뜻은 아닙니다.
도트 렌 그림은 사용자 요청으로76→50mm로 바꿨습니다. 돌기 중심을 원본x90px(발 중심)에 놓고18mm 폭·3T2.6mm 삽입깊이를 보존했습니다. 공통 받침과홈, 일반 렌 크기는 유지합니다. 새 곡선은 `scripts/len_dot_part.py`에서 `laser_paths.cut_path`로 생성합니다.

## 검사 범위

그림·백색·칼선에 같은 강체 변환을 적용합니다. 칼선은 원래 베지어 제어점을 직접 변환해 PDF Form 행렬 반올림 오차를 피합니다.
보호 원본30조각은 다시 피팅하지 않습니다. 위치가 바뀐 실제 칼선을 대조해 보호 원본으로 분류하며, 주변 사각 영역만 보고 다른 조각까지 보호 처리하지 않습니다.

내보내기 오차 상한은0.002mm입니다. 소유한 외곽을 곡선으로 정리할 때 양방향 거리 상한은0.035mm입니다.
미세 지그재그·중복·교차·열린 경로를 검사하고, PDF·AI·SVG·VectorCraft의5형식×9대지를 모두 확인합니다.
PNG 해상도, 원본 인쇄PDF와 마스터의 픽셀 일치, ZIP 필수 구성·누락·중복·해시도 검사합니다.
실제 검사 수와 보호 원본 발견 사항은 `LASER_PATH_AUDIT.json`, 전체 범위는 `RELEASE_VALIDATION.json`에 기록합니다.

## 제작 시 주의할 파일 구분

AI는 PDF 호환 레이어이며 네이티브 편집본은 VectorCraft입니다. 편집 그림은600ppi이고 원본 데이터를 유지한 인쇄PDF는 별도입니다.
파란 기준 사각형은 재단선이 아닙니다. 백색판이 없는 그림은 RIP에서 백색을 설정합니다.
실물은 미검증입니다. 카데나의 좌우 홈 약0.195mm 높이 차이와 원래3mm 돌기도 보존했습니다.
raw의 보관 해시 검사는 과거 불량 도안의 제작 승인이 아닙니다.

## 개별 에셋과 출력 배치

`python scripts/build_individual_assets.py`는 A3와 같은 고정 입력·생성기를 사용해 모든 현재 조각을 원본 방향·실물 크기로 분리합니다. `output/individual_assets`가 에셋별 AI/PDF·그림·백색·칼선 카탈로그이고, `output/a3_release`는 출력용 배치입니다. 개별 대지에는 외곽 밖2mm 여백만 둡니다. 그림은 원본을600ppi로 분리하고, 칼선은 이동만 하여 원래 베지어·구멍·홈을 유지합니다.

`verify_individual_assets.py`는 개별 경로를 각 A3 배치로 다시 변환해0.002mm 이내 일치와 레이어·그림을 검사하고 모든 PDF/AI를 렌더합니다. 전체 칼선 감사는 개별 4형식까지 포함합니다. 줄줄이 튀잉 예시는 기존4조각과 구멍 중심으로 합성한 참고 이미지이며 링은 재단 데이터에 포함하지 않습니다.

현재141개 조각의 검토한 원본 좌표 베지어는 `configs/individual_contours.json`에 고정합니다. 개별 에셋과 A3 생성기가 함께 읽습니다. 플랫폼별 수치 피팅으로 양검 받침에 약0.0234mm 차이가 생기는 사례를 발견하여, 게시된 A3의 실제 곡선을 기준으로 고정했습니다. 홈은 그대로이며 그림·기계치수는 변경하지 않습니다.

## 2026-11-23 어센트 별도 출력

사용자 요청으로 카데나와 별도로25조각(그림 있는 판21·받침4)을 A3 두 장에 배치합니다. 원본의 빈 패널31은 위치를 확인한 뒤 사용자가 제외했습니다. `11_ascent_remaining/3T`는 두 페이지이며 기존혼합판과 섞지 않습니다. 원본 크기104×62.807mm, 받침104×30mm, 돌기폭20mm·깊이3mm와 홈20.2×3.2mm를 유지합니다. `SIZE_VERIFICATION.json`과 `size_check.png`는 소프트웨어 치수 검증 자료이며 실물 끼움은 미검증입니다. 원본 받침의 좌우 홈 앞뒤차이 약0.195mm도 기록합니다. 별도2장 각각의14·11조각 중 후자는 빈 공간이 한쪽에 모이도록 배치했습니다.

확정 출력은 양검을 포함한 혼합2장59조각 + 별도어센트2장25조각 =4장84조각입니다. 별도배치 조건 아래 각 묶음이 면적하한2장에 도달합니다. PAD는 보류하고 원본만 보존합니다. 전수 범위는 A3 9대지·8ZIP·개별141에셋이며 기존 인쇄판 재커팅4형식까지 합쳐 칼선613파일입니다.

## 선택 세트를 추가 장수 없이 넣는 조건

양검 캐릭터·키링은 혼합1, 받침은 혼합2에 배치했습니다. 6개 기존 조각만 회전·이동하고 크기·칼선·구멍은 유지했습니다.
Len PAD를 원래 혼합56조각과 합치면 반 간격1.5mm 확장 면적의 하한231650.399mm²가 확장된 두 대지 면적의 상한231176mm²를 넘습니다. 따라서3mm 간격·8mm 가장자리에서2장 수용이 불가합니다. 이 증명은 단순 면적만 비교하는 것과 구분합니다.
어센트25조각과 PAD7조각은 면적 하한만으로 불가를 증명할 수 없습니다. 사각형 배치,33개 코어 배치의264회 외곽 채우기,13개 어센트 판+PAD받침을 먼저 고정한 뒤 나머지18조각의64회 외곽 배치를 시도했으나 유효한2장 배치를 확보하지 못했습니다. 이는 전역 불가능 증명이 아니며, 추가 장수를 쓰지 않으라는 지시에 따라 이번 출력에서는 보류합니다. `OPTIONAL_FILL_ASSESSMENT.json`에 수치와 탐색 한계를 기록합니다.
