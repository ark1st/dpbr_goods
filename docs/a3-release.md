# 현재 A3 제작판 · 개인별 스탠드·상하 연결 키링

**3T 아크릴에 A3 가로 420 × 297 mm, 실제 크기 100%**로 제작합니다. 조각 사이 간격은 3 mm 이상, 가장자리 여백은 8 mm 이상입니다. 가장자리에서 4 mm 안쪽의 파란 사각형은 위치 맞춤에 사용하며 재단에서 제외합니다.

| 출력 | 구성 | 조각 |
|---|---|---:|
| 1 | 기존 혼합 1 | 43 |
| 2 | 기존 혼합 2 | 16 |
| 3 | 어센트 14 + 개인 키링 1 | 15 |
| 4 | 어센트 11 + 개인 스탠드 12 + 개인 키링 1 | 24 |
| 5 | 나머지 개인 키링 | 12 |
| **합계** | **5장** | **110** |

기존 84조각은 위치, 크기, 칼선 곡선을 유지했습니다. 추가분은 4명분 스탠드 12조각(캐릭터 6개와 받침 6개)과 3명분 키링 14개입니다. 기존 대지 자투리에 스탠드 12조각과 키링 2개를 넣고, 나머지 키링 12개는 새 A3 한 장에 배치했습니다.

## 키링 수정

원본 `dpbr_of@59c513d`의 위쪽 연결부와 구멍을 유지하고, 아래에도 지름 4 mm 구멍이 있는 연결부를 추가했습니다. 아래 연결부 폭은 13 mm입니다. 구멍에서 그림까지 6 mm 이상, 칼선까지 약 4.5 mm를 확보했습니다. 그림 높이 40 mm를 유지했으므로 완성품 외곽은 4 × 4 cm를 넘으며, 위아래 연결부를 포함한 높이는 약 71 mm입니다.

그림은 보관된 준비 PNG를 그대로 사용했습니다. 연결용 금속 링은 별도 부속입니다. 실물의 링 간섭, 아크릴 끼움, 커프, 인쇄 정합은 아직 시험하지 않았습니다.

## 배치 근거와 한계

회전과 위치는 `configs/a3_placements.json`에 기록했습니다. 추가한 26조각의 외곽과 구멍은 함께 회전하고 이동합니다. 추가 배치의 최소 조각 간격은 3.10 mm입니다. 기존 84조각의 배치와 파란 기준선은 그대로입니다.

고정 배치 16개와 어센트 재배치 유효 후보 18개를 검토해 5장 배치를 확정했습니다. 검토 범위에서 4장 배치를 찾지 못했으며 4장 배치 가능성은 열려 있습니다. 배포 검사에는 전체 면적, 조각 간격을 반영한 면적 하한, 실제 장수를 각각 기록합니다.

Len PAD는 보류 중입니다. 양검은 혼합 1·2에 포함되어 있어 단독판은 참고용으로 보관합니다. 5T는 기존 제품의 대안이며 이번 개인별 도안은 3T로 제작합니다. 이미 인쇄한 500 × 800 mm 복구판은 별도 재커팅용으로 보관합니다.

## 재생성과 검사

```sh
python scripts/build_a3_release.py --only 11_ascent_remaining
python scripts/build_a3_release.py --only 19_personal_fill
python scripts/build_individual_assets.py --only-group 11_ascent_remaining
python scripts/build_individual_assets.py --only-group 19_personal_fill
python scripts/package_a3_release.py
python -m unittest discover -s tests
python scripts/verify_release.py
```

고정 커밋과 SHA-256 해시를 확인한 뒤 입력을 `tmp/source_cache`에 복원합니다. 개별 칼선의 기준 파일은 `configs/individual_contours.json`입니다. 개별 에셋 167개, 두께별 대안과 참고 대지 10개, 이미 인쇄한 복구판의 칼선을 검사합니다. 정확한 검사 범위와 수량은 출력의 `LASER_PATH_AUDIT.json`과 `RELEASE_VALIDATION.json`에 기록합니다.

현재 제작에는 각 시트 폴더의 PDF, PNG, AI와 VectorCraft 파일을 사용합니다. 이전 A3 ZIP 8개는 원격에 있던 내용 그대로 퇴역 보관하며 새 ZIP은 만들지 않습니다. 제공된 백색 분판은 그대로 유지합니다. 새 개인 도안의 백색 인쇄는 RIP에서 그림의 알파 채널을 기준으로 설정합니다.
