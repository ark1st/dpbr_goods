# A3 재배치·병합 기록

## 현재 배포: 압축 배치 / 카데나 / Len 일반+DOT

2026-11-21 후속 요청으로 실제 출력은 **A3 3장**입니다.

- 추가 이미지: 기존38조각 + 제공 새튀4개 =42조각, 3T/5T 중 하나.
- 어센트: 원본 첫 행 카데나4판 + 원본 첫 받침1개 =5조각. 다른 직업은 이번 출력에서 제외.
- Len: 공통 배경·받침 한 세트와 교체 캐릭터2종8조각 + 튀잉4 =12조각, 3T/5T 중 하나.

시험판·시험키·샘플은 사용자 요청으로 전부 제외합니다. 생성기와 검증기는 시험편의 재포함을 차단합니다.
기존 14조각 Len A3판(`fd57eab`)은 퇴역이며, 현재 12조각 파일로 교체합니다.

Len DOT 원격 `af8c02c99d9516501f0190984cf907bd52c3d030`의 도트 에셋·생성기·출력을 병합합니다.
일반/DOT 두 완성 세트 대신 공통 세트1개와 교체 캐릭터2종을 사용자가 명시적으로 선택했습니다.
공통6조각의 외곽·홈을 원본끼리 대조한 후 중복을 제거합니다. 캐릭터 두 조각은 각각 원본 크기입니다.
카데나는 원본 첫 줄의 붉은 머리 캐릭터이며 [공식 직업 소개](https://maplestory.nexon.com/Guide/N23Job/View/36)와 대조했습니다.
원본 객체 선택은 `configs/a3_release.json`의 `cadena_source_part_ids`에 고정했습니다.

현재 그룹과 키링 배정은 같은 설정 파일에서 관리합니다. `03_linked_keyrings`, `04_ascent_original`은 퇴역이며
manifest의 `retired_groups`로 명시합니다. 현재 제작 전수검사와 ZIP 검사는 활성5대지·5패키지만 대상으로 하며,
퇴역판은 별도 상태로 기록합니다. 이전 소스 검사126파일에 현재 A3 25파일을 더해 총151파일을 검사합니다.
보호 외부30개 원본의 발견사항은 별도 보고합니다. 현물 시험은 미완료입니다.

5T Len과 키링의 배치 회귀 검사는 실제12조각 치수 fixture로 한 장 수용·배율·간격·수량을 검사합니다.
Len은 실제 외곽으로 15도 간격 회전 배치를 탐색하고, 벡터 거리로 3mm 간격을 확인합니다. 검색용 마스크를 칼선으로 내보내지 않습니다.
겹치는 사각형 경계로 인쇄 그림이 중복되지 않도록 편집용 이미지는 각 조각만 따로 렌더합니다.
배치 탐색은 시드가 고정되어 재현 가능하며, 한 장에 안 들어가면 축소하지 않고 생성을 실패시킵니다.

아래는 이전 5장 배포 이력입니다. 현재 수량은 위3장을 따릅니다.

## 검사 범위

각 조각에 대해 그림·백색·재단에 같은 이동/회전을 적용합니다. 배율은 1입니다.
외부 30개 경로는 곡선 명령을 보존하며, 검사기의 보호 분류는 새 위치의 명시적 영역에 연결합니다.
단순히 예전 drawing index를 새 배치에 재사용하지 않습니다.
Len의 생성 외곽은 모두 `laser_paths.cut_path`를 통과시킵니다. 기존 오차 상한 0.035mm가 적용됩니다.
내보낸 원본 대비 배치 오차 상한은 0.002mm이며, 구멍·홈·돌기 등 모든 경로를 대조합니다.

전수 검사는 A3 SVG, AI, 레이어 PDF, CUT_ONLY PDF, VectorCraft를 포함합니다.
추가 A3 검사는 7개 대지의 수량, 실제 크기, PNG 300ppi, 원본 경로, 인쇄 PDF의 픽셀 일치, ZIP 파일 해시를 검사합니다.
구 527×204mm 추가 시트, 55×75mm 튀잉 시트, 320×370mm Len은 원본·참고용이며 현재 제작판으로 배포하지 않습니다.

PDF 인쇄 파일은 원래 그림 데이터를 보존합니다. AI는 PDF 호환 레이어 파일이며 VectorCraft 전용 편집 상태는 별도 파일입니다.
일부 편집 파일에는 크기를 유지한 600ppi 그림을 넣어 반복 클리핑으로 생기는 과도한 편집 데이터와 메모리 사용을 방지합니다.
재단은 항상 벡터이며, 인쇄 PDF에는 이 편집용 래스터화를 적용하지 않습니다.

실물 시험 미완료. 어센트의 3.2mm 홈·3mm 돌기, 좌우 홈 약 0.195mm 세로 차이, 받침 5개와 빈 효과판 1개는 제공 원본대로 보존합니다.
이 기록은 장비 커프·실제 판 두께·끼움·인쇄 정합을 보증하지 않습니다.
