# A3 제작판 · 스탠드 보강과 제로 합본

어센트는 별도 5T 800×500mm 판이며 아래는 나머지 3T / 가로420×297mm / 배율100% / 조각 간격3mm 이상 / 가장자리8mm 이상입니다. 파란 기준 사각형은 가장자리에서4mm이며 자르지 않습니다.

| 출력 | 구성 | 조각 |
|---|---|---:|
| A3 1 | 혼합1 + 개인 키링1 | 42 |
| A3 2 | 혼합2 | 13 |
| A3 3 | 개인 스탠드8 + 연결 키링4 | 12 |
| A3 4 | 개인 키링9 + Len PAD7 | 16 |
| 합계 | 4장 | 83 |

어센트 30조각과 단풍바람 단독 로고는 3T에서 제외했습니다. 캐릭터10개를4번에서3번으로 옮기고 신규스탠드4조각을3번에 추가했습니다. 본제작은87조각이며 최소장수는 증명하지 않았습니다. 제로 그림은 몸 크기와 발선에 맞춰 조정했고 Len 홈은 승인된 PR 보정값을 적용했습니다.

## 스탠드 수정

이전 스탠드는 무기 효과까지 포함한 그림 전체 중심에 돌기를 두고 낮은 연결부만 추가해, 몸통부터 돌기까지 좁은 목이 남을 수 있었습니다. 현재는 머리·몸통의 두꺼운 중심을 찾고 중간 몸통부터 폭26mm 투명 보강부를 내려 부드러운 곡면으로 돌기에 연결합니다. 실제 내보낸 외곽에서 탭 축을 포함하는 연속 단면 폭을 검사합니다. 분리된 조각의 폭을 더해 통과시키지 않습니다.

마가다락방(강민)과 청민예(강윤진)는 각각 알파·베타를 한 캐릭터 판에 합치고 받침 하나를 씁니다. 원본 픽셀 기준 공통 배율로 몸 크기와 발선을 맞추고 몸통 중심 간격을25mm로 좁혔습니다. 무기·효과는 일부 겹칩니다. 이상준·정지영은 단독 캐릭터를 유지합니다. 총 캐릭터 판4개와 투명 받침4개입니다.

돌기18×2.6mm, 받침72×28mm/R7, 홈18.8×3.0mm를 유지합니다. 보강부의 기하 검사는 실물 강도·끼움·커프·인쇄 정합 시험이 아닙니다.

## 키링과 원본 보존

줄줄이 키링14개의 그림·상하4mm 구멍·칼선은 이전 배포와 같습니다. 뿟쥐의 알파·베타도 키링에서는 각각 별도입니다. 제로 합본은 스탠드 두 종에만 적용합니다.

기존12개 스탠드 조각 중 중복되는 제로 캐릭터·받침4조각은 현재 목록에서 퇴역시켰습니다. 삭제 전 변경 전 전체 커밋4ffb44c를 raw에 스냅샷으로 올리고, 퇴역44개 파일의 SHA256을 실제 푸시된 보관본과 대조했습니다. 보관본은 새 제작 승인이 아닙니다. 과거 가는 연결부와 분리 제로판은 현재 출력에 사용하지 않습니다.

그림은 기존 준비PNG를 그대로 쓰며 생성형 이미지나 재그림을 사용하지 않습니다. 제공되지 않은 백색은 RIP에서 그림 알파 기준으로 설정합니다. 신규 ZIP은 생성하지 않습니다. 이전 A3 ZIP8개는 이전 버전 보관본입니다.

## 재생성과 검사

```sh
python scripts/build_a3_release.py --only 11_ascent_remaining
python scripts/build_a3_release.py --only 19_personal_fill
python scripts/build_individual_assets.py --only-group 11_ascent_remaining
python scripts/build_individual_assets.py --only-group 19_personal_fill
python scripts/package_a3_release.py
python -m unittest discover -s tests
python scripts/verify_release.py
```

입력은 tmp/source_cache에서 고정 커밋·SHA256으로 검증합니다. 검토 칼선은 configs/individual_contours.json, 회전·위치는 configs/a3_placements.json입니다. A3 10대지와 5T 대형판 1대지의5형식, 개별174조각의4형식, 기존 인쇄판 재커팅4형식으로 총755개 칼선을 검사합니다. 정확한 결과와 한계는 output의 검사 JSON을 따릅니다.

Len PAD와 양검은 현재 4장에 모두 포함됩니다. `06_len_pad`와 `09_yanggum` 단독판은 중복 참고본으로 유지하며 추가 출력하지 않습니다. PAD 받침280×71.2235mm와8개 홈도 원래 크기입니다. 이미 인쇄된500×800mm 복구판은 별도이며 새 인쇄 A3에 포함하지 않습니다.

## Len 홈 끼움 보정 (이슈 #1)

원본 Len 홈은 판 표기 두께와 같은18.8×3.0(5T는18.8×5.0)mm이고 칼 폭 보정이 없어 실물이 헐렁했습니다.
`configs/a3_release.json`의 `len_slot_fit`로 Len 일반·패드 받침의 홈8개씩만 다시 그립니다(`laser_paths.slot_path`).
홈 중심·방향·모서리반경0.35mm, 외곽·돌기·그림·보호 원본(카데나3.2×20.2 등)은 바꾸지 않습니다.

| 두께 | 칼 폭 | 판 두께 | 두께 여유 | 좌우 여유 | 그리는 홈 |
|---|---:|---:|---:|---:|---|
| 3T | 0.15 | 3.0 | 0.05 | 0.2 | 17.9×2.90mm |
| 5T | 0.20 | 5.0 | 0.05 | 0.2 | 17.8×4.85mm |

홈 너비 = 판 두께 + 두께 여유 − 칼 폭. 홈 길이 = 돌기18 + 좌우 여유 − 2×칼 폭(돌기도 칼 폭만큼 줄어듦).
값은 표준 시작값이며 실측이 아닙니다. 장비 칼 폭이나 판 실측 두께가 다르면 이 설정만 바꿔 다시 생성합니다.
`verify_a3_release.py`는 Len 시트마다 보정 홈8개·원래 치수 홈0개를 확인합니다.

## 원문 가이드와 이번 선택

[단풍바람 굿즈 만들기 원문](https://docs.google.com/document/d/1zasgvxLgu7rkULyPR1h_cZRGx2P14C4--0cpYaosGhA)을 다시 확인했습니다. 원문의 아크릴 포함 전체 높이60mm·원형 받침40mm 규격과 기존 보강형은 다릅니다. 사용자는2026-11-24 현재 보강형을 본 제작판에 유지하고, 원문 규격은 렘샤 한 세트만 별도 선택안으로 제작하도록 지정했습니다. 이 선택안은 본 제작4장87조각에 포함하지 않습니다. 원형 받침의4mm 구멍과18mm 돌기 장착홈을 구분하며, 실제 끼움은 미검증입니다. 빨간 칼선 RGB(255,0,0), 기존 승인0.001mm와 파란 대지 기준선을 유지합니다. 원문 칼선 두께 표기의 단위 오기는 기존AI 및 승인 제작 기록의0.001mm 기준을 따릅니다.
